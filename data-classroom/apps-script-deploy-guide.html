데이터 수업 웹앱

Apps Script 백엔드 배포 가이드

학생 웹앱의 공유 글과 제출 데이터를 교사용 Google Sheets에 자동으로 모으기 위한 설정입니다.

백엔드 코드 열기교사용 대시보드교사용 자료실

1. 수집용 Google Sheet 만들기

학교 Google 계정으로 Google Sheets를 새로 만들고 이름을 데이터수업_학생응답수집처럼 정합니다.
주소창의 /d/와 /edit 사이에 있는 긴 문자열이 스프레드시트 ID입니다.

2. Apps Script 프로젝트 만들기

Google Sheets에서 확장 프로그램 → Apps Script를 엽니다.
기본 Code.gs 내용을 모두 지우고, apps-script-backend.gs 내용을 붙여넣습니다.
코드 상단의 SPREADSHEET_ID 값을 내 수집용 Sheet ID로 바꿉니다.

3. 웹 앱으로 배포하기

배포 → 새 배포를 클릭합니다.
유형 선택에서 웹 앱을 선택합니다.
실행 사용자: 나
액세스 권한: 학교 정책에 맞게 선택합니다. 일반적으로 조직 내 사용자 또는 테스트 시 링크가 있는 사용자를 사용합니다.
배포 후 표시되는 웹 앱 URL을 복사합니다.

4. 학생·교사용 웹앱에 URL 연결하기

학생 웹앱과 교사용 대시보드 코드의 아래 값을 복사한 웹 앱 URL로 바꾸면 자동 수집이 켜집니다.

const SUBMIT_ENDPOINT = '여기에 Apps Script 웹 앱 URL'; const BACKEND_URL = '여기에 Apps Script 웹 앱 URL';

수정 후 GitHub Pages 반영까지 1~3분 정도 걸릴 수 있습니다.

개인정보 주의

학생의 반, 번호, 이름, 답안이 Google Sheet에 저장됩니다. 학교 Google Workspace 계정으로 운영하고, 공개 링크 배포 범위와 보관 기간을 학교 기준에 맞게 관리하세요.
